# Classic Explorer support

_Last updated: November 23, 2026_

Classic Explorer is published by Deck-Of-Jacks.

**Found a problem?** [Report an issue](https://github.com/IanD-Bot/support/issues/new?template=classic-explorer.yml)

## About this app

Classic Explorer is a classic-style file manager for Windows that you can use instead of File Explorer. It restores the classic look with new features: no ribbon, plus tabs, a full-path address bar, a right-click menu you control, and color tags. File operations go through Windows, with the same dialogs as File Explorer.

## Requirements

Windows 10 version 2004 (build 19041) or later, 64-bit. Windows 11 is the supported release; Windows 10 is best effort. Tags need folders on an NTFS drive.

## Install and launch

Install the app from the Microsoft Store, then open it from the Start menu. Once it's installed, File Explorer's right-click menu also has **Open in Classic Explorer** and a **Tags** submenu.

## Settings

Open **Settings** from the **See more** (...) menu.

- **Right-click menu** shows the live menu for the selected item next to every section and command. Move, hide or fold commands, pick section colors, turn the Classic menu off, or **Reset to defaults**.
- **Tags** renames the color tags, adds your own tags, and lists the folders where tags follow moves made by other apps.
- **Windows** has **Open folders in Classic Explorer** (off by default) and the new-window hotkey (Win+Shift+E by default).
- **Backup** has **Export setup...** and **Import setup...** for your views, right-click menu, hotkey, theme and tags.
- **Appearance** offers **Match Windows** (the default), **Light** or **Dark**. Open windows change at once, and Windows' high contrast always wins.

Settings and tags stay in the app's local data on your PC. Nothing is uploaded.

## Common questions

- **How do I tag a file?** Select it and use the Tags button on the toolbar, the right-click menu, or the details pane (Alt+Shift+P). Search with `tag:` and a tag name, such as `tag:Work`, or pick a tag in the left pane.
- **Do tags follow my files?** Yes, for renames and moves on the same NTFS drive, including ones made by other apps in the folders listed on the Tags page. A copy doesn't keep the original's tags.
- **Where is the full Windows right-click menu?** Choose **Show more options** at the bottom of the menu, or press Shift+F10 or Shift+right-click.
- **Can folders open in Classic Explorer by default?** Yes, on Windows 11: turn on **Settings > Windows > Open folders in Classic Explorer**. Turning it off puts the earlier settings back exactly.
- **Can I move my setup to another PC?** Use **Settings > Backup > Export setup...**, then **Import setup...** on the other PC. Tagged items are matched by path, and items that aren't there are skipped.

## Reset and uninstall

To reset the right-click menu, use **Reset to defaults** on the Right-click menu page. Before uninstalling, turn off **Open folders in Classic Explorer** if you turned it on. If you forget, the first folder you open afterwards puts File Explorer back. To remove the app, uninstall it from Settings > Apps.
